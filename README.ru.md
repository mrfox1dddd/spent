# Spent

[English](README.md) · **Русский**

Приватный опенсорсный трекер экранного времени для Android. Показывает, сколько вы сидите в каждом приложении и сколько уведомлений оно присылает. Все данные остаются на устройстве, у приложения вообще нет доступа в интернет.

## Возможности

- Время по приложениям за день, неделю, месяц, год и всё время
- Суточный циферблат за сегодня
- Счётчик уведомлений по приложениям
- Страница приложения: время, запуски, уведомления
- Экспорт всей истории в CSV или JSON
- Светлая и тёмная темы, три акцентных цвета
- Русский и английский

## Приватность

- В манифесте нет разрешения `INTERNET`, поэтому приложение физически не может ничего отправить. Проверить можно самому: `aapt2 dump permissions app-release.apk`.
- Никакой аналитики, рекламы, отчётов о сбоях и сторонних SDK.
- Текст уведомлений не читается и не хранится. Считается только, какое приложение прислало уведомление и когда.
- Список всех установленных приложений (`QUERY_ALL_PACKAGES`) не запрашивается.
- Облачный бэкап выключен. История переезжает на новый телефон только прямым переносом с устройства на устройство.
- Экспорт сохраняется туда, куда вы укажете в системном окне выбора файла.

## Разрешения

Нужны два доступа, оба выдаются вручную в настройках системы:

- **Доступ к статистике использования** (`PACKAGE_USAGE_STATS`): без него Android не сообщает, сколько времени вы провели в приложениях.
- **Доступ к уведомлениям**: нужен, чтобы считать входящие уведомления.

## Как считаются данные

- Android хранит подробную историю использования только около недели, а для более старых дней отдаёт укрупнённые итоги. Spent ведёт ежедневный архив в локальной базе, поэтому длинные периоды работают. Дни, взятые из укрупнённых итогов, помечены как приблизительные (приглушённые столбцы) и без числа запусков.
- Почасовые данные хранятся 35 дней.
- Уведомления считаются с момента выдачи доступа. Историю до этого не может получить ни одно приложение.
- Сам Spent и лаунчеры в статистику не входят.
- Агрессивная экономия батареи (Xiaomi, Huawei и похожие) может останавливать слушатель уведомлений. Если счётчик занижен, разрешите автозапуск и снимите ограничения по батарее для Spent.

## Экспорт

CSV (UTF-8 с BOM, переводы строк CRLF) и JSON (`{app, format, exported_at, rows}`). Одна строка на пару «день + приложение», колонки `date, package, app, usage_ms, launches, notifications, approx`. Пустое значение означает «неизвестно».
